# Design

A product team reads a report at a workbench in daylight, with hardware samples beside the laptop. A light, neutral surface keeps long reading comfortable. Honey orange marks decisions and proposed parts. Deep aubergine provides contrast on a few system pages.

## Direction

An illustrated field report from a small engineering studio. Physical photographs, contact sheets, generous sans-serif titles, marginal notes, and precise system drawings. This brief is explicitly editorial.

## Palette

Primary: oklch(0.55 0.13 60). Accent: oklch(0.28 0.06 315). Background: oklch(1 0 0). Surface: oklch(0.965 0 0). Ink: oklch(0.20 0.015 315). Secondary text: oklch(0.45 0.015 315).

## Type

Chivo for headings and body. Source Serif 4 for reflective passages. Use system fallbacks. Embed selected Latin font files in the standalone export.

## Layout

A report with a compact sticky contents rail on wide screens and horizontal navigation on small screens. A visual opening, an irregular moodboard, comparison tables, and long-form chapters. Use strong diagram labels and enough white space for reading.

## Interaction

A small device-state simulator and a capacity cost model with adjustable assumptions. Label both as design tools. Print styles expose all report content without page navigation.

## Character

Steel Marty takes his name from martensite. Use the founder’s supplied character sheet without alteration. Keep the faceted body and two blue eyes on color displays. Use a simple black silhouette with white eyes on CoreInk. State text and the last sync time remain authoritative. A pose changes only when the recorded state changes.

## Eyes

The founder supplied an eye exploration sheet. Keep vertical eyes as the signature. The proposed device vocabulary uses small dots for quiet, vertical lines for working, large dots for decisions, raised eyes for completion, and horizontal lines for offline. Confirm meanings in user tests at native resolution. Always include status text and the last sync time.
